# Simpell (A Simple Shell)

Simpell is a simple command-line shell written entirely in C++ from scratch.

The project began as an experiment to understand how shells work internally. Instead of relying on existing parsers, Simpell implements its own tokenizer and command interpreter, allowing users to execute custom commands such as arithmetic operations, folder creation, directory navigation, and system information.

This project is continuously evolving and serves as a learning journey into systems programming, interpreters, and eventually operating system development.

## Current Features

- Custom tokenizer
- Interactive shell loop
- Command interpreter
- Basic arithmetic (`add`, `sub`, `multiply`, `divide`)
- Folder creation
- Directory navigation (`goto`)
- Current date & time
- Basic text file operations
- Error handling for invalid commands

## Planned Features

- Variable support
- Command suggestions ("Did you mean...?")
- File explorer commands
- Scripting support
- Plugins
- Better parser architecture
